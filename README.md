
# wordofmouth-react

This is a ready-to-run Vite + React scaffold for the WordOfMouth FE assignment.
It contains:
- Product mock page with live counters, social proof widgets, reviews, comments, and a popup.
- Two visual variations (toggle using the Switch or Variation buttons).

## How to run (locally)

### Prerequisites
- Node.js (v16+) and npm installed.
- Recommended: VS Code + Live Server (optional).

### Steps (Windows PowerShell)
1. Open PowerShell and navigate to the project folder:
   ```
   cd path\to\wordofmouth-react
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Start dev server:
   ```
   npm run dev
   ```
4. Open the URL shown in the terminal (usually http://localhost:5173).

### Steps (macOS / Linux)
1. Open terminal:
   ```
   cd /path/to/wordofmouth-react
   npm install
   npm run dev
   ```

### Notes
- If you prefer a static no-build version, open `index.html` at the project root (but with Vite paths the images are inside /public).
- Replace images in `/public` with real product images if you want.
